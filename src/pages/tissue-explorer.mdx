# 🧬 组织数据浏览器

在这里可以搜索和浏览组织数据，包括组织特性、ECM成分和特殊挑战。

<TissueExplorer />

## 使用提示

1. **按物种过滤** - 选择特定的物种（如人、小鼠、大鼠等）
2. **按ECM成分过滤** - 输入ECM成分（如胶原蛋白、层粘连蛋白等）
3. **调整显示数量** - 选择每页显示的记录数
4. **导出结果** - 支持导出为 CSV 或 JSON 格式
