## 其他数据浏览工具

- **组织数据查询** - 搜索组织特性和推荐的解离酶
- **单细胞数据集** - 浏览公开的 scRNA-seq 数据
- **空间组学数据** - 查看组织空间分布
- **蛋白质信息** - 搜索蛋白质和修饰信息

## 使用提示

1. **按类型过滤** - 选择特定的酶类型（如胶原酶、蛋白酶等）
2. **按组织过滤** - 输入目标组织名称
3. **调整显示数量** - 选择每页显示的记录数
4. **导出结果** - 支持导出为 CSV 或 JSON 格式
