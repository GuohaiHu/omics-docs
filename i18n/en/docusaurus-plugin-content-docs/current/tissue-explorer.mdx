#  Tissue Data Browser

Here you can search and browse tissue data, including tissue characteristics, ECM components and special challenges.

<TissueExplorer />

## Usage Tips

1. **Filter by organism** - Select specific species (human, mouse, rat, etc.)
2. **Filter by ECM component** - Enter ECM component (collagen, laminin, etc.)
3. **Adjust display count** - Choose number of records per page
4. **Export results** - Support export to CSV or JSON format
