# Multi-omics Database

Welcome to the Multi-omics Database platform, a comprehensive resource for DNA, cell, spatial, and proteomics data integration and analysis.

## Features

- **DNA Omics**: Genomic analysis, sequencing data, and variant calling
- **Cell Omics**: Single-cell RNA-seq, enzyme databases, and tissue profiles  
- **Spatial Omics**: Visium, MERFISH, ISS imaging and analysis
- **Proteomics**: Mass spectrometry data, protein quantification, and PTM analysis

## Quick Start

1. Browse the documentation in the left sidebar
2. Use the Data Explorer to view enzyme and tissue databases
3. Run analysis pipelines on your data
4. Access API endpoints for programmatic access

## Data Resources

- **Enzyme Database**: Comprehensive enzyme annotation and functional classification
- **Tissue Database**: Tissue-specific molecular profiles and characteristics
- **Analysis Tools**: Statistical analysis and visualization workflows
