#  Single-Cell Knowledge Base

The single-cell knowledge base is the core knowledge resource of the Cell Omics module, covering key technical materials and data references throughout the single-cell experimental workflow.

## Content Overview

| Submodule | Description |
|-----------|-------------|
| [Single-Cell Dissociation Enzyme Database](enzyme_database) | Commercial enzyme overview, enzyme selection logic, and critical control points |
| [Single-Cell Dissociation Tissue Database](tissue_database) | Tissue ECM components, recommended enzyme combinations, and references for human, mouse, and other species |

## Applicable Scenarios

- Query optimal dissociation enzyme combinations when designing single-cell experiments
- Quickly match recommended digestion protocols based on tissue type
- Understand substrate specificity, optimal pH, and vendor information for different enzymes

>  **To be supplemented**: Additional species tissue data, plant tissue dissociation protocols, organoid dissociation protocols, etc.
