#  Getting Started

Welcome to the Multi-Omics Database! This guide will help you get started quickly.

##  What is Multi-Omics?

Multi-omics refers to the simultaneous measurement and analysis of multiple molecular layers within the same biological sample, including:

- **DNA Omics**: Genomic variation, copy number changes
- **Cell Omics**: Gene expression at the single-cell level
- **Spatial Omics**: Transcriptomics with preserved spatial information
- **Proteomics**: Protein expression and interactions

##  Three-Minute Quick Navigation

### Looking for experimental protocols?
 Go to ** Cell Omics** > **Protocols**

### Querying enzyme information?
 Click ** Data Explorer** at the top to search by enzyme name or catalog number

### Need tissue database?
 Go to ** Cell Omics** > **Tissue Database**

### Want to learn technical details?
 Visit the **Methods** section of the corresponding omics module

##  Frequently Asked Questions

**Q: How do I get dissociation protocols for specific tissues?**
A: Use the Data Explorer to filter the "Tissue" column, or refer to the Tissue Database in Cell Omics.

**Q: How often is data updated?**
A: We update data regularly; the latest information is published in the blog.

**Q: Can I export data?**
A: Supports export in multiple formats including CSV and JSON.
