# 🔍 Enzyme Data Explorer

Search and browse various data in the Multi-omics Database.

## Enzyme Database Query

<EnzymeExplorer />

## Other Data Browsing Tools

- **Tissue Data Query** - Search tissue characteristics and recommended dissociation enzymes
- **Single-cell Datasets** - Browse public scRNA-seq data
- **Spatial Omics Data** - View tissue spatial distribution
- **Protein Information** - Search proteins and modification information

## Usage Tips

1. **Filter by Type** - Select specific enzyme types (e.g., collagenase, protease, etc.)
2. **Filter by Tissue** - Enter target tissue name
3. **Adjust Display Count** - Choose the number of records per page
4. **Export Results** - Supports export to CSV or JSON format
