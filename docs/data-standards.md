#  数据标准

本文档定义了多组学数据库中使用的数据标准和规范。

## 概述

统一的数据标准确保了数据的可比性、可重复性和可互操作性。

## 术语

| 术语 | 定义 |
|------|------|
| **样本** | 生物来源的材料 |
| **组织** | 来自特定器官的材料 |
| **细胞类型** | 特定的细胞分类 |
| **处理条件** | 施加于样本的实验条件 |

## 数据格式

### 表格数据
- 格式：CSV、TSV
- 编码：UTF-8
- 分隔符：逗号（CSV）或制表符（TSV）

### 序列数据
- 格式：FASTA、FASTQ
- 压缩：Gzip（.gz）

### 图像数据
- 格式：TIFF、H5AD
- 分辨率：标准化要求见各板块指南

## 命名规范

```
{物种}_{组织}_{处理条件}_{批次号}
```

示例：`human_liver_collagenase_batch001`

## 质量控制

所有提交的数据需经过以下检查：
- [ ] 数据完整性
- [ ] 格式合规性
- [ ] 元数据准确性
- [ ] 质量指标达标
