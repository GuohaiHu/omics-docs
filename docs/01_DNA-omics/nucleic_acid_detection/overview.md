#  核酸检测技术概述

核酸检测是连接核酸提取与下游应用（文库构建、测序、PCR 等）的关键质控环节。准确的核酸定量与纯度评估是实验成功的基础保障。

## 检测在组学流程中的位置

```
样本采集 → 核酸提取 → 【核酸检测】 → 文库构建 → 测序 → 数据分析
                    ↑
              浓度 / 纯度 / 完整性
```

## 主要检测指标

| 指标 | 检测意义 | 常用方法 |
|------|---------|---------|
| **浓度（Concentration）** | 确定投入量，计算稀释倍数 | 分光光度法、荧光法 |
| **纯度（Purity）** | 检测蛋白、有机溶剂等污染物 | A260/A280、A260/A230 |
| **完整性（Integrity）** | 评估核酸降解程度 | 凝胶电泳、毛细管电泳 |
| **片段大小（Size）** | 确认片段分布是否符合要求 | 生物分析仪、片段分析仪 |

## 常用检测技术分类

### 1. 光谱法（Spectrophotometry）

基于核酸在 **260 nm** 波长处的紫外吸收特性进行定量。可同时检测 A260/A280 和 A260/A230 比值评估纯度。

**代表设备**：NanoDrop、普通紫外分光光度计

### 2. 荧光法（Fluorometry）

利用特异性荧光染料（如 PicoGreen、RiboGreen、Qubit 试剂）与核酸结合后发出荧光信号，灵敏度远高于光谱法，且不受游离核苷酸干扰。

**代表设备**：Qubit 荧光计

### 3. 电泳法（Electrophoresis）

利用琼脂糖凝胶分离不同大小的核酸片段，通过染料显色观察条带完整性和分布。

**代表设备**：水平电泳槽、凝胶成像系统

### 4. 毛细管电泳法（Capillary Electrophoresis）

在毛细管中利用电场分离核酸片段，结合荧光检测实现高分辨率的大小分布分析和完整性评分。

**代表设备**：Agilent Bioanalyzer（2100/4150）、Agilent Fragment Analyzer、TapeStation

## 检测策略建议

| 实验阶段 | 推荐检测组合 | 目的 |
|---------|-------------|------|
| **提取后** | NanoDrop + Qubit | 快速评估纯度与精确定量 |
| **文库构建前** | Qubit + Bioanalyzer/TapeStation | 精确定量 + 完整性/片段大小评估 |
| **文库构建后** | Qubit + Bioanalyzer/TapeStation | 文库浓度 + 插入片段大小分布 |
| **上机前** | Qubit + qPCR（KAPA） | 精确定量可测序文库分子数 |
