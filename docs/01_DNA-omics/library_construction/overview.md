#  文库构建技术概述

测序文库（Sequencing Library）是指经过片段化、末端修复、接头连接等处理后，带有特定平台接头序列的 DNA 片段集合。文库构建是连接原始核酸与测序仪器的核心桥梁。

## 文库构建在测序流程中的核心地位

```
提取的 DNA/RNA → 【文库构建】 → 质量控制 → 上机测序
```

文库质量直接决定：
- 测序数据的产量与有效数据比例
- 碱基质量与比对率
- 变异检测的灵敏度与准确性

## 通用构建步骤

1. **片段化（Fragmentation）**
   - 机械剪切（超声破碎）、酶切消化或靶向扩增
2. **末端修复（End Repair）**
   - 将黏性末端修复为平末端，或进行 A 尾修饰
3. **接头连接（Adapter Ligation）**
   - 连接平台特异性接头（Y 型接头、发夹接头等）
4. **片段筛选 / 纯化（Size Selection / Cleanup）**
   - 磁珠或凝胶回收目标大小片段
5. **PCR 扩增（可选，Amplification）**
   - 富集连接成功的片段，并引入 Index/Barcode
6. **质量控制（Quality Control）**
   - qPCR、Bioanalyzer 或 Qubit 验证

## 短读长 vs 长读长文库构建的核心差异

| 维度 | 短读长文库 | 长读长文库 |
|------|-----------|-----------|
| **投入 DNA 量** | 较低（ng–μg 级） | 较高（μg 级）；需高分子量 DNA |
| **片段大小** | 150–800 bp | 10 kb – `>100 kb |
| **接头设计** | Y 型双端接头，双 Index | 发夹接头（PacBio）；连接接头（ONT） |
| **PCR 循环数** | 通常 4–12 轮 | 通常 0–5 轮（偏好无 PCR） |
| **建库时间** | 3–6 小时 | 1–2 天 |
| **片段化方式** | 超声破碎或酶切 | 尽量无片段化（保护 HMW DNA） |
