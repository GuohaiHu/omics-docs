#  长读长文库构建技术

长读长文库构建（Long-Read Library Preparation）与短读长文库有本质区别：核心挑战在于**保护高分子量 DNA（High Molecular Weight, HMW）** 的完整性，并尽量降低 PCR 扩增带来的偏向性。

## 核心特点

| 特点 | 说明 |
|------|------|
| **HMW DNA 要求** | 通常需要 > 30 kb，理想 > 50 kb；PacBio HiFi 和 ONT 超长读长对 DNA 质量要求极高 |
| **低投入量挑战** | 部分长读长应用（如单细胞、微量样本）需要在极低 DNA 量下建库 |
| **无 PCR 偏好** | 尽可能减少或避免 PCR 扩增，保留原始分子信息 |
| **特殊接头设计** | 发夹接头（PacBio SMRTbell）、连接接头（ONT）与短读长 Y 型接头截然不同 |

## PacBio HiFi 文库构建流程

### 1. DNA 质量评估

- **FemtoPulse / Pulsed-Field Gel**：评估 HMW DNA 完整性
- **要求**：DNA 片段 > 50 kb，无显著降解拖尾

### 2. 片段大小选择（可选）

- **BluePippin / SageELF**：根据目标读长选择特定大小范围（如 15–20 kb、> 30 kb）
- 对于 HiFi 模式，通常选择 15–20 kb 的片段

### 3. 末端修复与连接发夹接头

- **SMRTbell 接头**：发夹结构（Hairpin Adapter），两端连接后形成"哑铃"状文库分子
- **DNA 损伤修复**：修复 AP 位点、切口等损伤，提升测序质量

### 4. 结合聚合酶与上机

- 文库分子结合测序引物和 DNA 聚合酶
- 加载到 SMRT Cell 的 Zero-Mode Waveguide（ZMW）中进行测序

### 5. 特点

- **HiFi 模式**：通过多次读取同一分子（CCS，Circular Consensus Sequencing）获得 > 99.9% 准确率的长读长
- **无 PCR 偏好**：原始分子信息完整保留

## Oxford Nanopore 文库构建流程

### 1. DNA 质量评估

- **FemtoPulse**：评估片段大小分布
- **要求**：根据应用不同，可从 1 kb 到 > 100 kb

### 2. 片段化或修复（可选）

- **超长读长**：尽量保持原始 HMW DNA，不做片段化
- **常规读长**：可使用 Fragmentase 或超声适度打断
- **末端修复**：修复 5' 和 3' 末端，为连接做准备

### 3. 连接测序接头

- **ONT 接头**：包含马达蛋白（Helicase）结合位点和膜锚定序列
- **可选条形码（Barcode）**：使用 Native Barcoding Kit 进行多样本标记

### 4. 上机测序

- 文库加载到 Flow Cell，马达蛋白解旋 DNA 单链通过纳米孔
- 实时产生电信号数据

### 5. 特点

- **实时测序**：数据边测边出，可随时终止
- **直接检测修饰**：无需亚硫酸氢盐处理即可检测 5mC 等 DNA 修饰
- **超长读长潜力**：世界纪录已达 4 Mb 以上

## 短读长 vs 长读长文库构建对比

| 对比维度 | 短读长文库 | 长读长文库（PacBio） | 长读长文库（ONT） |
|---------|-----------|---------------------|------------------|
| **DNA 质量要求** | 可容忍降解 | HMW > 50 kb | HMW 为优，但可容忍一定降解 |
| **片段化** | 必须 | 尽量保护 HMW | 可选 |
| **PCR 扩增** | 通常需要 | 无（原始分子） | 可选（快速建库有 PCR） |
| **接头结构** | Y 型双端 | SMRTbell 发夹 | 线性连接 |
| **建库时间** | 3–6 小时 | 1–2 天 | 10 分钟–数小时 |
| **文库复杂度** | 高 | 依赖原始 DNA 量 | 高 |

## 样本制备特殊要求

| 要求 | 说明 |
|------|------|
| **温和提取** | 避免剧烈涡旋、过度吹打；推荐使用磁珠法或柱提法中的温和方案 |
| **避免冻融** | HMW DNA 在冻融过程中易断裂，建议分装后 -80°C 保存 |
| **快速处理** | 样本离体后尽快处理，防止内源性核酸酶降解 |
| **片段筛选** | 根据目标读长选择合适的大小筛选方案 |
