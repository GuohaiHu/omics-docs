#  测序技术概述

测序技术（Sequencing Technology）是 DNA 组学的核心驱动力。从 1977 年 Sanger 测序法诞生至今，测序技术经历了三次重大技术革命。

## 测序技术发展历程

```
第一代测序（Sanger, 1977） → 第二代测序（NGS, ~2005） → 第三代测序（TGS, ~2010+）
```

| 代际 | 读长 | 通量 | 代表平台 | 核心特点 |
|------|------|------|---------|---------|
| **第一代** | 500–1,000 bp | 极低 | ABI 3730 | 双脱氧链终止法，金标准验证 |
| **第二代** | 50–300 bp | 超高 | Illumina、MGI | 边合成边测序，成本极低 |
| **第三代** | 10 kb – `>2 Mb | 中等 | PacBio、ONT、Cyclonseq | 单分子实时测序，超长读长 |

## 短读长 vs 长读长测序核心差异

| 维度 | 短读长测序（Short-Read） | 长读长测序（Long-Read） |
|------|------------------------|------------------------|
| **准确率** | 极高（> 99.9%） | 高（HiFi > 99.9%；ONT ~ 99%） |
| **读长** | 50–300 bp | 10 kb – `>100 kb |
| **通量** | 海量（Tb 级/ run） | 大（Gb–Tb 级/ run） |
| **单碱基成本** | 极低 | 中等 |
| **结构变异检测** | 困难 | 优秀 |
| **高重复区域** | 难以跨越 | 轻松跨越 |
| **单倍型分型（Phasing）** | 受限 | 可达染色体级别 |
| **甲基化直接检测** | 需要特殊文库（WGBS） | 可直接检测（ONT） |

## 主流测序平台概览

| 平台 | 技术原理 | 读长 | 优势 | 局限 | 最佳应用场景 |
|------|---------|------|------|------|-------------|
| **Illumina** | 边合成边测序（SBS） | 2×150 bp | 市场生态完善，短读长数据准确度高 | 存在潜在的 PCR 扩增偏好性与测序偏倚 | WGS、WES、RNA-seq、标准 NGS 应用 |
| **MGI（华大智造）** | cPAS / DNBSEQ | 2×100 bp | 扩增错误率极低，Index 串扰小，性价比极高 | 读长受限，难以跨越极其复杂的高重复序列区域 | WGS、人群队列、超高通量项目 |
| **PacBio** | SMRT / HiFi | 10–25 kb | HiFi 模式兼具长读长与极高准确率（> 99.9%） | 测序试剂成本相对较高，整体通量不及主流短读长平台 | 从头组装、结构变异、表观遗传 |
| **Oxford Nanopore（ONT）** | 纳米孔测序 | 10 kb – `>2 Mb | 读长极长（可达 Mb 级），实时输出数据，可直接检测甲基化修饰 | 原始单碱基错误率较高（尤其是同聚物区域） | 实时测序、超长读长、现场检测 |
| **华大序风（Cyclonseq）** | 纳米孔单分子测序 | 超长读长 | 国产自主可控，超长读长，设备具备小型便携潜力 | 单碱基准确率仍在持续优化中 | 现场快速检测、超长读长应用 |

## 技术选择决策树

```
您的核心研究目标是什么？
├── 高准确率 + 低单碱基成本 → 短读长测序（Illumina / MGI）
├── 从头组装 / 结构变异 / 全长转录本 → 长读长测序（PacBio HiFi）
├── 实时测序 / 超长读长 / 便携性 → 长读长测序（ONT / 华大序风）
├── 国产自主可控 / 现场快速检测 → 华大序风（Cyclonseq）
├── DNA 甲基化直接检测 → ONT、PacBio 或 华大序风
└── 平衡成本与分辨率 → 混合策略（短读长 + 长读长）
```
