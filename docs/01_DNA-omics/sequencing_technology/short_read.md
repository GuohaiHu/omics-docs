#  短读长测序技术

短读长测序（Short-Read Sequencing）以 Illumina 和 MGI（华大智造）为代表，是目前应用最广泛、技术生态最成熟的高通量测序技术。

## 核心技术原理

### Illumina 边合成边测序（Sequencing by Synthesis, SBS）

1. **簇生成（Cluster Generation）**
   - 文库分子与 Flow Cell 表面引物杂交
   - 通过桥式 PCR（Bridge PCR）扩增形成光学可分辨的克隆簇（Cluster）

2. **测序反应**
   - 加入四种带有不同荧光基团的可逆终止子核苷酸（dNTP）
   - DNA 聚合酶每次延伸一个碱基，荧光信号被 CCD 相机捕获
   - 化学切除荧光基团和终止基团，进入下一轮延伸

3. **碱基识别**
   - 根据每轮荧光颜色和强度确定碱基序列
   - 同时生成对应的质量值（Q-score / Phred Score）

### MGI cPAS / DNBSEQ 技术

1. **DNA 纳米球（DNA Nanoball, DNB）制备**
   - 滚环扩增（RCA）形成 DNB，避免指数扩增的偏好性

2. **联合探针锚定聚合（cPAS）**
   - DNB 加载到规则阵列化的硅芯片上
   - 采用与 Illumina SBS 类似的荧光检测原理进行测序
   - 但基于 DNB 的线性扩增方式，从根本上避免了桥式 PCR 的指数扩增偏好性

3. **核心优势**
   - **扩增错误率极低**：DNB 采用滚环扩增（RCA），无指数扩增的偏好性与错误累积
   - **Index 串扰（Hopping）率极低**：显著低于 Illumina 桥式 PCR 体系，更适合多文库混池测序
   - **性价比极高**：测序试剂与运行成本具有明显优势，尤其适合大规模人群队列与超高通量项目
   - **读长局限**：与 Illumina 类似，读长受限（目前主流为 2×100 bp），难以跨越极其复杂的高重复序列区域

## 测序流程概述

```
文库变性 → 杂交上样 → 簇生成/DNB加载 → 测序反应 → 成像采集 → 碱基识别 → 数据输出
```

## 关键性能指标

| 指标 | Illumina NovaSeq X Plus | MGI DNBSEQ-T7 |
|------|------------------------|---------------|
| **单次运行通量** | ~16 Tb | ~6 Tb |
| **读长** | 2×150 bp | 2×100 bp |
| **运行时间** | ~48 小时 | ~24 小时 |
| **Q30 占比** | > 85% | > 85% |
| **Index 串扰率** | 较低 | 极低 |

## 主流机型对比

| 机型 | 定位 | 通量 | 读长 | 适用场景 |
|------|------|------|------|---------|
| **NovaSeq X Plus** | 超大规模 | 最高 | 2×150 bp | 国家级队列、大型 WGS 项目 |
| **NovaSeq 6000** | 大规模 | 高 | 2×150 bp | 临床检测、大型科研 |
| **NextSeq 2000** | 中规模 | 中 | 2×150 bp | 中小型项目、快速周转 |
| **DNBSEQ-T7** | 超大规模 | 高 | 2×100 bp | 人群基因组、超高通量 |
| **DNBSEQ-G400** | 中大规模 | 中高 | 2×100 bp | 临床与科研兼顾 |

## 典型应用场景

- **全基因组测序（WGS）**：变异检测、群体遗传学
- **全外显子测序（WES）**：遗传病诊断、肿瘤靶向 panel
- **RNA 测序（RNA-seq）**：基因表达、可变剪接、融合基因
- **ChIP-seq / ATAC-seq**：表观遗传调控研究
- **甲基化测序（WGBS / RRBS）**：DNA 甲基化图谱
