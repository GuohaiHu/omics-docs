#  长读长测序技术

长读长测序（Long-Read Sequencing）以 PacBio（Pacific Biosciences）、Oxford Nanopore Technologies（ONT）以及华大序风（Cyclonseq）为代表，突破了短读长难以跨越重复区域和复杂结构变异的瓶颈。

## PacBio 单分子实时测序（SMRT / HiFi）

### 核心原理

1. **Zero-Mode Waveguide（ZMW）**
   - 纳米级孔道结构，底部固定 DNA 聚合酶
   - 每次只允许一个 DNA 分子进入检测区域

2. **荧光标记核苷酸**
   - 四种 dNTP 分别标记不同荧光基团，荧光基团连接在磷酸基团上
   - 当核苷酸被聚合酶掺入新链时，荧光信号在 ZMW 底部被激发和检测
   - 掺入后荧光基团随焦磷酸一起释放，不残留于 DNA 链上

3. **HiFi 模式（High-Fidelity）**
   - 利用 SMRTbell 发夹接头，聚合酶绕环反复读取同一模板
   - 通过多轮共识（Circular Consensus Sequencing, CCS）纠错
   - 最终获得 **> 99.9% 准确率** 的长读长（10–25 kb）

![PacBio SMRT 测序原理](/img/sequencing/Pacbio-principle.png)

### 测序流程

```
SMRTbell 文库加载 → 聚合酶-ZMW 结合 → 实时荧光检测 → 原始读长（Subread）
    ↓
CCS 纠错（多轮读取同一分子） → HiFi 读长（高质量共识序列）
```

### 性能特点

| 指标 | 典型值 |
|------|--------|
| **HiFi 读长** | 10–25 kb（可选 15–20 kb 为最佳平衡点） |
| **HiFi 准确率** | > 99.9%（Q30+） |
| **单次运行通量** | 90–130 Gb（Revio 平台） |
| **运行时间** | 24–30 小时 |

## Oxford Nanopore 纳米孔测序

### 核心原理

1. **纳米孔蛋白（Nanopore Protein）**
   - 嵌入脂质双分子层的通道蛋白（如 CsgG、R9/R10 系列）
   - 孔径仅允许单链 DNA/RNA 通过

2. **电流信号检测**
   - 单链 DNA 在马达蛋白（Helicase）驱动下通过纳米孔
   - 不同碱基（或 k-mer，如 5-mer）通过时引起特征性电流扰动
   - 实时记录电流变化，通过碱基识别算法（Basecaller）转换为序列

3. **直接修饰检测**
   - 甲基化等化学修饰会改变电流特征
   - 无需亚硫酸氢盐转化即可直接检测 5mC、5hmC 等修饰

![ONT 纳米孔测序原理](/img/sequencing/ONT.png)

> 适用 Gemini 生产的图片

### 测序流程

```
文库加载 → 马达蛋白解旋 → DNA 单链通过纳米孔 → 实时电流信号采集
    ↓
碱基识别（Basecalling） → 原始读长（Raw Read）
```

### 性能特点

| 指标 | 典型值 |
|------|--------|
| **读长范围** | 10 kb – `>100 kb（常规）；>1 Mb（超长读长） |
| **原始准确率** | ~99%（R10.4.1 化学 + Bonito/Dorado） |
| **单次运行通量** | 可达 Tb 级（PromethION 48） |
| **运行时间** | 实时，可持续 72 小时 |
| **设备特点** | 从便携（MinION）到高通量（PromethION） |

## 华大序风（Cyclonseq）纳米孔测序

### 核心原理

1. **纳米孔单分子测序技术**
   - 基于蛋白质纳米孔或固态纳米孔，单链 DNA/RNA 在马达蛋白驱动下通过纳米孔道
   - 不同碱基通过孔道时引起特征性电流变化，通过碱基识别算法转换为序列

2. **国产自主可控**
   - 拥有自主知识产权的纳米孔测序芯片与碱基识别算法
   - 从芯片、试剂到分析软件的全链条国产化

3. **设备形态**
   - 序风系列单分子测序仪涵盖不同通量需求
   - 设备具备小型化与便携化潜力，适合现场快速检测场景

![华大序风 CycloneSeq 测序原理](/img/sequencing/CycloneSeq.png)

> 适用 Gemini 生产的图片

### 性能特点

| 指标 | 典型值 |
|------|--------|
| **读长范围** | 超长读长（可达数百 kb 及以上） |
| **单碱基准确率** | 仍在持续优化中 |
| **设备特点** | 国产自主可控，具备小型便携潜力 |

### 测序流程

```
文库加载 → 马达蛋白解旋 → DNA 单链通过纳米孔 → 实时电流信号采集
    ↓
碱基识别（Basecalling） → 原始读长（Raw Read）
```

## PacBio vs ONT vs 华大序风 对比

| 对比维度 | PacBio HiFi | Oxford Nanopore | 华大序风（Cyclonseq） |
|---------|-------------|-----------------|----------------------|
| **核心原理** | 荧光标记 + ZMW + CCS 纠错 | 电流信号 + 纳米孔 + 碱基识别 | 电流信号 + 纳米孔 + 碱基识别 |
| **读长** | 10–25 kb（HiFi） | 10 kb – `>2 Mb | 超长读长（可达数百 kb 及以上） |
| **准确率** | > 99.9%（HiFi） | ~99%（原始）；可达 Q20+ | 可达 Q20+ |
| **通量** | 中等（Gb–百 Gb） | 高（Gb–Tb） | 中等（单芯片可达400 Gb） |
| **运行时间** | 固定（约 24–30 h） | 实时可控（分钟–数天） | 实时可控 |
| **设备成本** | 高（Revio ~$1M） | 低–高（MinION ~$1K；PromethION ~$200K） | 中等 |
| **直接修饰检测** | 可通过 kinetic 信号间接检测 |  可直接检测 5mC 等 | 可直接检测 |
| **RNA 直接测序** | （需逆转录） |  RNA 直接测序（无需逆转录） | RNA 直接测序（无需逆转录） |
| **现场/便携** | 否 |  MinION 可现场使用 | 具备小型便携潜力 |
| **自主可控** | 进口 | 进口 | 国产自主可控 |

## 典型应用场景

- **de novo 基因组组装**：跨越重复序列，获得端粒到端粒（T2T）基因组
- **结构变异检测**：精确识别 > 50 bp 的插入、缺失、倒位、易位
- **全长转录本测序**：ISO-seq / cDNA-seq 获得完整 mRNA 异构体
- **表观遗传学**：直接检测 DNA 甲基化（ONT / 华大序风）或结合 kinetic 信号（PacBio）
- **宏基因组学**：16S/ITS 全长测序，精确到种/株水平的物种鉴定
