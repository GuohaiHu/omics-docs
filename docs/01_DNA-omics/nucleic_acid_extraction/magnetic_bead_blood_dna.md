#  MGI 磁珠法血液 DNA 提取技术方案

DNA 提取是基因组学研究的基石，其核心目标是高效释放核酸并去除蛋白质、脂质及其他抑制物。本方案以华大智造（MGI）磁珠法血液基因组 DNA 提取试剂盒为参考，详细说明其分子原理与操作路径。

## 一、 核心技术原理

磁珠法提取的核心利用了**超顺磁性纳米微粒**在特定生化环境下的吸附特性。相比传统的离心柱法，它具有高度的自动化兼容性，且无需反复离心，对大分子量 DNA 的机械损伤更小。

### 1. 裂解阶段 (Lysis)
* **核心试剂**：蛋白酶 K (Proteinase K)、裂解液 (含盐酸胍等离液盐)
* **作用机制**：利用强变性剂破坏细胞膜与核膜，蛋白酶 K 同步降解组蛋白及核酸酶。
* **结果**：基因组 DNA 从细胞核内释放，游离于裂解体系中。

### 2. 结合阶段 (Binding)
* **核心试剂**：特异性磁珠、结合液 (通常含异丙醇)
* **作用机制**：在“高盐、低 pH”环境下，水分子脱离核酸表面，暴露出带负电的磷酸骨架。
* **磁珠互动**：表面修饰有特定官能团（如羟基或硅醇基）的磁珠通过静电引力和氢键与 DNA 特异性结合。

### 3. 洗涤阶段 (Washing)
* **核心试剂**：洗涤液 1 & 2 (主要含 70%-80% 乙醇)
* **作用机制**：通过外加磁场将“磁珠-DNA 复合体”固定，利用含乙醇的洗涤液去除残留的蛋白质、无机盐及代谢产物。
* **关键点**：乙醇环境能维持 DNA 与磁珠的紧密结合，同时物理冲刷掉杂质。

### 4. 洗脱阶段 (Elution)
* **核心试剂**：洗脱缓冲液 (Elution Buffer, 如 Tris-HCl 或无核酸酶水)
* **作用机制**：切换至“低盐、高 pH”的洗脱缓冲液。
* **结果**：磁珠与 DNA 之间的斥力增加，水化层重建，高纯度 DNA 重新溶解并回收。

## 二、 简要实验流程 (以 200μL 全血为例)

> **注意：** 实际操作请严格参考所购 Kit 的官方版本说明书（如 V1.2 或更新版本）。

| 步骤 | 操作说明 | 核心试剂添加 | 关键参数 |
| :--- | :--- | :--- | :--- |
| **1. 样本预处理** | 取 200 μL 抗凝全血至反应管/孔板中 | 血液样本 | 需充分混匀 |
| **2. 消化裂解** | 加入蛋白酶 K 及裂解液 | **20 μL Pro K + 200 μL Lysis Buffer** | 56°C 孵育 10-15 min |
| **3. 核酸结合** | 加入磁珠悬液及结合液，震荡混匀 | **20-30 μL 磁珠 + 200 μL Binding Buffer** | 室温结合 5-10 min |
| **4. 磁性分离** | 放置磁架，静置至液体澄清，吸弃上清 | 无 | 严禁吸走磁珠 |
| **5. 多轮洗涤** | 加入洗涤液重悬磁珠，再次磁分离吸弃上清 | **500 μL Wash Buffer (含乙醇)** | 通常洗涤 2-3 次 |
| **6. 干燥磁珠** | 磁架上静置，利用余温或空气使乙醇挥发 | 无 | 观察磁珠表面由亮变暗 |
| **7. 洗脱回收** | 加入洗脱液，重悬孵育 | **50-100 μL Elution Buffer** | 56°C 孵育 5 min |
| **8. 转移保存** | 磁分离后，将含有 DNA 的上清转移至新管 | 无 | A260/280 应在 1.8-2.0 |
