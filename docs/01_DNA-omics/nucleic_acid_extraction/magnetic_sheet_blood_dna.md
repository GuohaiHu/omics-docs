#  磁片法提取血液 DNA

## 概述

磁片法（Magnetic Sheet / Automated Magnetic Rod Extraction）本质上是磁珠提取法的全自动化升级形式，利用磁棒或磁片在预装试剂条/板中自动完成裂解、结合、洗涤和洗脱全过程，是目前高通量血液 DNA 提取的主流自动化方案。

## 原理简介

1. **自动裂解**：仪器自动加入裂解液，恒温裂解白细胞释放 DNA
2. **磁珠结合**：磁珠在磁场作用下吸附 DNA
3. **自动洗涤**：磁棒转移磁珠至洗涤液中，多次洗涤去除杂质
4. **自动洗脱**：磁珠转移至洗脱液中，释放纯化 DNA

## 适用样本类型

- EDTA 抗凝全血
- 枸橼酸钠抗凝全血
- 大规模队列筛查样本

## 方法特点

| 维度 | 说明 |
|------|------|
| **优点** | 全自动、高通量（96/192 样本/批）、一致性最好、人工干预最少 |
| **缺点** | 设备投入成本高、灵活性差、难以处理特殊样本 |
| **提取时间** | 约 30–60 分钟/批（取决于程序设定） |
| **典型纯度** | A260/A280 ≈ 1.8–2.0 |

## 常用设备

| 设备名称 | 厂家 | 通量 | 特点 |
|---------|------|------|------|
| **KingFisher** 系列 | Thermo Fisher | 96/24 孔 | 经典磁棒式提取仪，应用最广 |
| **BioSprint** | Qiagen | 96 孔 | 配合专用试剂盒，稳定性好 |
| **Nextractor** 系列 | 国产 | 96 孔 | 性价比高，适合本土化应用 |

## 关键注意事项

-  血液样本需在采集后尽快处理，避免长时间室温放置
-  不同抗凝剂样本需选用对应试剂盒程序
-  定期校准磁棒位置，防止磁珠残留影响纯度
