#  Trizol 法提取动物组织 RNA

## 概述

Trizol 法是目前实验室最经典、应用最广泛的总 RNA 提取方法之一，基于 **异硫氰酸胍-酚-氯仿一步法** 原理，特别适用于动物组织样本的总 RNA 提取。

## 原理简介

1. **裂解与 RNase 灭活**：异硫氰酸胍迅速裂解细胞并彻底灭活 RNase
2. **相分离**：加入氯仿离心后形成三层：
   - 上层水相：含 RNA
   - 中间层：含 DNA
   - 下层有机相：含蛋白质
3. **RNA 沉淀**：异丙醇沉淀水相中的 RNA
4. **洗涤纯化**：75% 乙醇洗涤去除盐类
5. **溶解**：无 RNase 水溶解 RNA

## 适用样本类型

- 新鲜动物组织（肝脏、脑、肌肉、心脏等）
- 液氮速冻后保存的组织样本
- 培养细胞沉淀

## 方法特点

| 维度 | 说明 |
|------|------|
| **优点** | 适用范围广、成本低、可同时分离 DNA/RNA/蛋白 |
| **缺点** | 接触有毒试剂（苯酚/氯仿）、操作步骤较多、对技术有要求 |
| **提取时间** | 约 1–1.5 小时 |
| **典型 RIN** | ≥ 7.0（新鲜组织） |

## 关键注意事项

-  **全程低温**：裂解后的操作尽量在冰上或 4°C 进行
-  **无 RNase 环境**：使用 DEPC 水、无 RNase 耗材，戴手套并频繁更换
-  **勿吸到中间层**：吸取水相时避免吸到中间蛋白层和下层有机相
-  **勿过度干燥**：RNA 沉淀干燥过度会导致难以溶解

## 组织样本特殊注意

| 组织类型 | 特殊挑战 | 建议 |
|---------|---------|------|
| **肝脏** | RNase 丰富、糖原多 | 增加裂解液用量，充分匀浆 |
| **脑组织** | 脂质含量高 | 可额外用氯仿抽提一次 |
| **肌肉** | 结缔组织多 | 充分剪碎或液氮研磨 |
| **脂肪组织** | 脂肪干扰 | 裂解后 4°C 静置，去除上层脂肪 |

## RNA 质量评估

| 指标 | 正常范围 | 评估意义 |
|------|---------|---------|
| **RIN 值** | ≥ 7.0（理想 ≥ 8.0） | 完整性指标；< 6.0 不建议用于 RNA-seq |
| **A260/A280** | 1.8 – 2.1 | 蛋白/酚污染检测 |
| **A260/A230** | 2.0 – 2.2 | 碳水化合物/硫氰酸盐污染检测 |
| **琼脂糖凝胶** | 28S/18S ≈ 2:1 | 真核 RNA 应见清晰双条带 |
