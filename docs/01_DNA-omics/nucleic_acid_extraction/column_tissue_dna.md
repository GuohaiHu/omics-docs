#  柱提法提取动物组织 DNA

## 概述

柱提法（Silica Membrane Column-based Extraction）基于硅胶膜在高盐条件下对 DNA 的特异性吸附原理，是目前实验室提取动物组织 DNA 最常用的方法之一。

## 原理简介

1. **组织裂解**：蛋白酶 K 消化蛋白质，释放基因组 DNA
2. **结合**：在高盐环境下，DNA 特异性结合于硅胶膜
3. **洗涤**：去除蛋白质、RNA 及其他杂质
4. **洗脱**：低盐缓冲液或水洗脱纯化 DNA

## 适用样本类型

- 新鲜动物组织（肝脏、肌肉、脾脏、肾脏等）
- 冷冻保存的组织样本
- 部分 FFPE 样本（需配合修复步骤）

## 方法特点

| 维度 | 说明 |
|------|------|
| **优点** | 操作简便、成本低、重复性好、纯度较高 |
| **缺点** | 需离心步骤、通量受限、对 HMW DNA 回收率有限 |
| **提取时间** | 约 30–60 分钟 |
| **典型纯度** | A260/A280 ≈ 1.8–2.0 |

## 关键注意事项

-  组织需充分研磨或剪切，确保完全裂解
-  避免交叉污染，每份样本使用独立耗材
-  洗脱液需预热至 55–70°C，提高 DNA 回收率
