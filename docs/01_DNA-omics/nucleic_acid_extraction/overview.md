#  DNA 和 RNA 提取技术概述

核酸提取（Nucleic Acid Extraction）是所有下游分子生物学实验的基础步骤。提取的 DNA 和 RNA 的质量与完整性直接决定了测序数据的可靠性和分析结论的准确性。

## 核酸提取的重要性

高质量的核酸是以下实验成功的先决条件：
- 准确的变异检测（Variant Calling）与基因分型
- 可靠的基因表达定量分析
- 成功的文库构建与高通量测序
- 可重复的实验结果

## DNA 与 RNA 提取的关键差异

| 特征 | DNA | RNA |
|---------|-----|-----|
| **稳定性** | 稳定、耐降解 | 脆弱、极易降解 |
| **结构** | 双链（Double-stranded） | 单链（Single-stranded） |
| **提取环境** | 标准实验条件 | 必须严格无 RNase（RNase-free） |
| **质量评估指标** | 完整性、纯度（A260/A280） | RIN 值、纯度、完整性 |
| **储存条件** | -20°C 长期保存 | -80°C，避免反复冻融 |

## 提取质量对下游测序的影响

低质量的核酸提取可能导致：
- 文库产量低、测序深度不足
- 基因组区域覆盖偏差
- 变异检测中的假阳性/假阴性
- 表达定量分析不准确
