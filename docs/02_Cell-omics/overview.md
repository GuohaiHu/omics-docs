#  细胞组学概述

细胞组学（Cell omics）在单细胞或单核水平研究细胞内的分子，揭示细胞间的异质性。

## 定义

细胞组学包含：
- **单细胞转录组学**：scRNA-seq
- **单细胞蛋白质组学**：流式细胞术、CyTOF
- **单细胞表观遗传学**：scATAC-seq
- **多参数检测**：多重免疫荧光

## 核心技术

| 技术 | 原理 | 分辨率 | 通量 | 应用 |
|------|------|--------|------|------|
| **scRNA-seq** | 转录分析 | 单细胞 | 高 | 细胞类型分类 |
| **流式细胞术** | 蛋白质检测 | 单细胞 | 高 | 细胞表型分析 |
| **scATAC-seq** | 表观遗传 | 单细胞 | 中 | 调控元素研究 |
| **CyTOF** | 质量分析 | 单细胞 | 中 | 蛋白表达谱 |
| **多重荧光** | 图像分析 | 纳米级 | 中 | 空间表达 |

### 关键步骤

1. **细胞解离**：将组织解离成单细胞
   - 选择合适的酶
   - 优化解离时间和温度

2. **细胞分选**：获得目标细胞群体
   - 流式细胞术分选
   - 磁珠分选

3. **捕获和富集**：
   - 微流控捕获
   - 液滴微囊泡
   - 芯片捕获
