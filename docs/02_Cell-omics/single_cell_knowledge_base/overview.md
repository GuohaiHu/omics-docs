#  单细胞知识库

单细胞知识库是细胞组学模块的核心知识资源，涵盖单细胞实验全流程中的关键技术资料与数据参考。

## 内容概览

| 子模块 | 说明 |
|--------|------|
| [单细胞解离酶学知识库](enzyme_database) | 商业化酶制剂总览、酶选择逻辑与关键控制点 |
| [单细胞解离组织成分数据库](tissue_database) | 人源/小鼠/其他物种的组织 ECM 成分、推荐酶组合与参考文献 |

## 适用场景

- 设计单细胞实验方案时查询最佳解离酶组合
- 根据组织类型快速匹配推荐消化方案
- 了解不同酶的作用底物、最佳 pH 和供应商信息

>  **待补充**：更多物种组织数据、植物组织解离方案、类器官解离方案等。
