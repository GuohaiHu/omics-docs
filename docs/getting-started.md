#  快速开始

欢迎来到多组学知识库！本指南将帮助您快速上手。

##  什么是多组学？

多组学是指在同一生物样本中，同时进行多种分子层面的测量和分析，包括：

- **基因组学**：DNA omics，简称D，以高通量测序为核心，获取物种/个体的完整遗传信息（基因组、表观基因组等）。使用的技术包括WGS、bulk RNAseq、Metagenomics；根据测序技术，又可以分为短读长测序（short read sequencing）和长读长测序（long read sequencing）。
- **细胞组学**：Cell omics，简称C，借助单细胞测序技术，在单细胞水平对细胞的基因表达、免疫组、蛋白和表观特性进行分析
- **空间组学**：STOmics，简称S，借助时空组学技术，在保留空间位置的基础上，进一步对组织/细胞的基因表达、免疫组和表观特征分子特征进行检测
 - **蛋白组学**：Proteomics，简称P，指通过高通量技术，对样本多蛋白/超多蛋白进行定量或者相对定量的测定
