#  空间组学技术方法

## 1. Visium 技术

### 原理
- 10X Genomics 开发
- 基于原位测序
- 捕获阵列：55 μm 间距
- 每张幻灯片最多 4 个样本

### 工作流

#### 步骤 1：样本制备
- 新鲜冷冻组织
- 切片厚度：10 μm
- 组织部分 H&E 染色

#### 步骤 2：原位杂交和逆转录
1. 组织固定和通透
2. 加入 Visium 试剂盒
3. 原位逆转录（RT）
4. 第二链合成

#### 步骤 3：空间条形码捕获
- 每个位置包含唯一 DNA 条形码
- 捕获局部 mRNA

#### 步骤 4：测序
- 高通量测序
- 获得转录本-位置映射

### 数据分析

```bash
# 使用 Space Ranger 处理原始数据
spaceranger count --id=sample_id \
                  --transcriptome=reference \
                  --fastqs=fastq_dir \
                  --slide=V19L01-041 \
                  --area=A1
```

## 2. MERFISH（多重误差鲁棒 FISH）

### 特点
- **高多重性**：可同时检测 500+ 基因
- **高分辨率**：~300-500 nm
- **定量**：单分子检测

### 操作流程

1. **探针设计**
   - 每个基因 18-25 条探针
   - 多重条形码标记

2. **样本处理**
   - 固定和通透
   - 背景去除

3. **多轮成像**
   - 每轮成像不同基因集
   - 共 10-20 轮

4. **图像处理**
   - 配准和合并
   - 单细胞分割

## 3. ISS（原位测序）

### 原理
- 组织内原位合成和读取 DNA 序列
- 超高分辨率：200-300 nm
- 3D 成像能力

### 流程

```
固定的组织
    ↓ 获取点
DNA 链合成
    ↓ 合成 & 成像循环
获取碱基信息
    ↓ 多轮循环
完整序列
    ↓ 空间映射
```

## 4. 成像质量标准

| 指标 | 标准 | 评价 |
|------|------|------|
| 信噪比 | &gt;3 | 良好 |
| 背景 | &lt;20% | 可接受 |
| 漂移 | &lt;100 nm | 优秀 |
| 重叠 | &gt;90% | 良好 |
